01. Hyperlink: Detail Benua

Buka benua_daftar.blade.php, tambahkan hyperlink untuk {{$benua->nama_benua}}

    <ul>
        @foreach($data_benua as $benua)
        <li>
            <a href="/benua-detail/{{$benua->id}}">{{$benua->nama_benua}}</a>
        </li>
        @endforeach
    </ul><

02. Route: /benua-detail/

Buat route untuk /benua-detail/{id} di routes/web.php untuk metode benua_detail di BenuaController

    Route::get('/benua-detail/{id}', [BenuaController::class, 'benua_detail']);

03. Metode: benua_detail

Tambahkan metode benua_detail pada BenuaController lalu kirim id benua sebagai argumen

    public function benua_detail($idb)
    {
        $benuaModel = Benua::find($idb);
        return view('benua_tampil_detail', ['data_benua' => $benuaModel]);
    }

04. File: benua_tampil_detail.blade.php

Buat file benua_tampil_detail.blade.php di resources/views lalu gunakan Extends dan Section

    @extends('navbar/navbar')
    @section('konten_utama')

    <div>

        <h4>{{$data_benua->nama_benua}}</h4>

    </div>
                
    @endsection

05. Hyperlink: Hapus Benua

Masih di benua_tampil_detail.blade.php, tambahkan tombol hyperlink untuk hapus benua

    @extends('navbar/navbar')
    @section('konten_utama')

    <div>

        <h4>{{$data_benua->nama_benua}}</h4>

    </div>
    
    <br><a href="/benua">Kembali</a> | 
    <a href="/benua-hapus/{{$data_benua->id}}">Hapus</a> | 
                
    @endsection

06. Route: /benua-hapus/


    Route::get('/benua-hapus/{id}', [BenuaController::class, 'benua_hapus']);

07. Metode: benua_hapus

Tambahkan metode untuk benua_hapus di BenuaController, tangkap id lalu jadikan argumen

    public function benua_hapus($idb)
    {
        $benuaModel = Benua::find($idb);
        $benuaModel->delete();

        return redirect('/benua');
    }



    # problem
    Error 404 - Not Found

    # solver
    Cek kembali penulisan value href="" dan penulisan link pada routes

Kembali ke benua_tampil_detail.blade.php, tambahkan tombol hyperlinnk untuk ubah benua

    @extends('navbar/navbar')

    @section('konten_utama')
    <div>

        <h4>{{$data_benua->nama_benua}}</h4>

    </div>
    
    <br><a href="/benua">Kembali</a> |

    <a href="/benua-ubah/{{$data_benua->id}}">Ubah</a> |

09. Route: /benua-ubah/


    Route::get('/benua-ubah/{id}', [BenuaController::class, 'benua_ubah']);

10. Method: benua_ubah

Tambahkan metode untuk benua_ubah di BenuaController, tangkap id lalu jadikan argumen

    public function benua_ubah($idb){

        $benuaModel = Benua::find($idb);
        return view("benua_ubah_form", ["data_benua" => $benuaModel]);

    }

11. File: benua_ubah_form.blade.php

Buatkan file benua_ubah_form.blade.php di resources/views, pastikan menggunakan Extends dan Section

    @extends('navbar/navbar')
    @section('konten_utama')

    <form action="/benua-ubah-proses/{{$data_benua->id}}" method="post">
    @csrf
        <input type="text" name="nama_benua" value="{{$data_benua->nama_benua}}">
        <input type="submit" name="simpan">
    </form>

    @endsection

12. Route: /benua-ubah-proses/


    Route::post('/benua-ubah-proses/{id}', [BenuaController::class, 'benua_ubah_proses']);

13. Method: benua_ubah_proses

Tambahkan metode untuk benua_ubah_proses di BenuaController, tangkap id lalu jadikan argumen

    public function benua_ubah_proses(Request $request, $idb)
    {
        $benuaModel = Benua::find($idb);
        $benuaModel->update($request->all());
        
        return redirect("/benua/" . $idb);
    }
