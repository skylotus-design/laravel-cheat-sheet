02. Tombol Hapus Benua

Buka file benua_tampil_detail.blade.php dan perhatikan tombol hapus

    <a href="/benua-hapus/{{$data_benua->id}}">Hapus</a> | 
    <a href="/benua-ubah/{{$data_benua->id}}">Ubah</a> | 

    <a href="/negara-hapus/{{$data_benua->id}}">Hapus Negara</a> |
    <a href="/negara-tambah/{{$data_benua->id}}">Tambah Negara+</a>
Tombol Hapus mengarah ke benua-hapus/{id} yang akan menjalankan metode benua_hapus_proses pada BenuaController

    Route::get('/benua-hapus/{id}', [BenuaController::class, 'benua_hapus_proses']);

02. BenuaController: ubah kode

Ubah kode di dalam metode benua_hapus pada BenuaController menjadi

    public function benua_hapus_proses($id){

        $benuaModel = Benua::find($id);
        $dataGambar = Peta::where('benua_id', $id)->get();

        foreach($dataGambar as $gambar){
            if(File::exists('img/peta/' . $gambar->nama_gambar)){
                File::delete('img/peta/' . $gambar->nama_gambar);
            }
        }
        
        $benuaModel->delete();
        return redirect('/benua');
    }



    # solver
    use App\Models\Peta;
    use Illuminate\Support\Facades\File;
