02. Hyperlink: Tambah Negara

    <br><a href="/benua">Kembali</a> |

03. Route: /negara-tambah/

Buat route untuk /negara-tambah/{id} di routes/web.php, untuk menjalankan metode negara_tambah di NegaraController

    Route::get('/negara-tambah/{id}', [NegaraController::class, 'negara_tambah']);



    # solver
    use App\Http\Controllers\NegaraController;

04. Make: NegaraController


    CMD: php artisan make:controller NegaraController
Buka NegaraController yang berada di app\Http\Controller lalu tambahkan metode negara_tambah

    public function negara_tambah($id)
    {
        return view('negara_tambah_form', ['idnya' => $id]);
    }

05. File: negara_tambah_form.blade.php

Buatkan file negara_tambah_form.blade.php di recources/views

    @extends('navbar/navbar')
    @section('konten_utama')

    <form action="/negara-tambah-proses/{{$idnya}}" method="post">

        <input type="hidden" name="benua_id" value="{{$idnya}}">

    </form>

    @endsection

06. Make Migration: create_negara_table


    # solver
    CMD: php artisan make:migration create_negara_table
Buka file migration create_negara_table yang ada di direktori database\migrations lalu ubah menjadi:

    Schema::create('negara', function (Blueprint $table) {
        $table->id();
        $table->string('nama_negara', 255);
        $table->foreignId('benua_id')->references('id')->on('benua')->onDelete('cascade');
        $table->timestamps();
    });
Jalankan migration untuk membuat tabel negara di MySQL

    # solver
    CMD: php artisan migrate

07. Make: Model Negara


    # solver
    CMD: php artisan make:model Negara
Buka file model Negara di app\Models lalu tambahkan kode berikut di dalam class agar tabel negara di MySQL dapat dikenali dan dapat di-insert

    protected $table = "negara";
    protected $fillable = ["nama_negara", "benua_id"];

08. Insert: Nama Negara

Reload http://127.0.0.1:8000/benua-detail/ di browser lalu klik tombol Tambah Negara+

    # problem
    Call to undefined method App\Http\Controllers\BenuaController::negara_tambah()

    # solver
    Cek kembali pengejaan pada route, pastikan penulisan NegaraController::class,
    bukan BenuaController::class



    # problem
    View [negara_tambah] not found.

    # solver
    Cek kembali Controller, pastikan penulisan view("negara_tambah_form", ['data_benua' => $benuaModel]);
    bukan view("negara_tambah", ['data_benua' => $benuaModel]);

09. Route: /negara-tambah-proses/


    Route::post('/negara-tambah-proses/{id}', [NegaraController::class, 'negara_tambah_proses']);

10. Metode: negara_tambah_proses

Buka NegaraController, lalu tambahkan metode negara_tambah_proses dan tangkap id yang dikirim melalui route

    public function negara_tambah_proses(Request $req, $id)
    {
        $negaraModel = Negara::create($req->all());
        return redirect('/benua-detail/' . $id);
    }

11. Model: HasMany

Buka kembali model Benua lalu tambahkan metode berikut:

    public function negaranya()
    {
        return $this->hasMany(Negara::class, 'benua_id', 'id');
    }



    # solver
    use App\Models\Negara;

12. BenuaController: with Negara

Buka kembali BenuaController, lalu cari metode benua_detail kemudian ubah kode menjadi

    public function benua_detail($id){

        $benuaModel = Benua::with('negaranya')->find($id);
        return view('benua_detail', ['data_benua' => $benuaModel]);

    }

15. Route: /negara-hapus/


    Route::get('/negara-hapus/{id}', [NegaraController::class, 'negara_hapus']);

16. Metode: negara_hapus

Tambahkan metode negara_hapus di NegaraController, dan tangkap id yang dikirim melalui route

    public function negara_hapus($idb)
    {
        $negaraModel = Negara::where('benua_id', $idb)->get();
        return view('negara_hapus', ['data_negara' => $negaraModel, 'id_benua' => $idb]);
    }

17. File: negara_hapus.blade.php

Buat file negara_hapus.blade.php di resources/views untuk memunculkan opsi hapus negara

    @extends('navbar/navbar')
    @section('konten_utama')

    <h5>Hapus Negara</h5><hr>

    <ul>
        @foreach($data_negara as $negara)
        <li>{{$negara->nama_negara}} |
            <a href="/negara-hapus-proses/{{$negara->benua_id}}/{{$negara->id}}"> Hapus</a>
        </li>
        @endforeach
    </ul><br>

        @if($data_negara->isNotEmpty())
            <a href="/benua-detail/{{$id_benua}}">Kembali</a>
        @else
            <span>Belum memiliki daftar negara</span> | 
            <a href="/negara-tambah/{{$id_benua}}">Tambah Negara+</a>
        @endif

    @endsection

18. Route: /negara-hapus-proses/


    Route::get('/negara-hapus-proses/{idb}/{idn}', [NegaraController::class, 'negara_hapus_proses']);

19. Metode: negara_hapus_proses

Tambahkan metode negara_hapus_proses di NegaraController, tangkap id benua dan id negara yang dikirim melalui route

    public function negara_hapus_proses($idb, $idn){

        $negaraModel = Negara::find($idn);
        $negaraModel->delete();

        return redirect('/negara-hapus/' . $idb);
    }
