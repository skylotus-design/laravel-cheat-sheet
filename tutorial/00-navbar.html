01. Membuat Navigation Bar

Buat folder navbar di direktori resources/views dan buat navbar.blade.php

    <!doctype html>
    <html lang="en">
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width, initial-scale=1">
        <title>Belajar Laravel</title>
        <link href="https://cdn.jsdelivr.net/npm/bootstrap@6.0.0-alpha.1/dist/css/bootstrap.min.css" rel="stylesheet">
    </head>
    <body>
        
        <main class="container my-5">

        <a href="/latihan">Home</a> | <a href="/benua">Daftar Nama-Nama Benua</a><hr><br><br>
      
        @yield('konten_utama')

        </main>

        <script type="module" src="https://cdn.jsdelivr.net/npm/bootstrap@6.0.0-alpha.1/dist/js/bootstrap.bundle.min.js"></script>
    </body>
    </html>

02. Extends dan Section

Atur semua kode yang dibuat di resources views menadi di dalam section

    @extends('navbar/navbar')

    @section('konten_utama')  
    <div>
        <ul>
        @foreach($data_benua as $benua)
            <li>{{$benua->nama_benua}}</li>
        @endforeach
        </ul>
    </div>
    @endsection
